# VD FIT UI Preview

VD FIT 体重管理界面的完整交互预览。页面为静态前端示例，不接入真实 AI 或用户数据库。

## 体验流程

首页 → 填写资料 → 拍摄引导 → 分析演示 → 专属报告。

- 身高、体重、腰围必填，报告同步填写值与计算出的 BMI。
- 正面、侧面照片可以在本地选择，不会上传。
- 使用指南完整显示，点击可放大查看原图。
- 使用支持区采用品牌 Logo；点击“查看支持方式”后显示原二维码。
- 保存后留在报告页，以轻提示告知文件已准备好。
- 保存文件包含方案长图与两张高清指南原图。

## 运行

直接打开 `index.html`，或通过 GitHub Pages 浏览。图片、样式、脚本与指南均已内嵌，不需要构建工具或额外服务器。

所有填写数据和所选照片仅用于当前浏览器内的预览，不持久保存，不请求外部分析服务。页面上的体态建议为示例，不能作为实际 AI 分析结果。

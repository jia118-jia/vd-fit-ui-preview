# VD FIT UI Preview — V30

手机、平板与电脑自适应交互预览。静态前端，无需服务器或数据库。

首页 → 填写身高、体重、腰围与五项问答 → 正侧面照片 → 分析演示 → 评分报告与专属体重管理方案。

## 自评规则

五项生活习惯各20分，每题三个选项分别为4、12、20分。五项完整后才生成总分；空项显示待填写。未通过照片推算体重、体脂率或健康风险。规则是产品自评映射，不是临床量表，未经临床验证。示例答案须点击后才填入并清楚标注。

维度方向参考 WHO 饮食和活动建议、CDC 体重管理建议：
- https://www.who.int/news-room/fact-sheets/detail/healthy-diet
- https://www.who.int/news-room/fact-sheets/detail/physical-activity/
- https://www.cdc.gov/healthy-weight-growth/losing-weight/index.html

BMI和腰高比从填写值独立计算，不计入习惯分。建议随自评结果调整。照片只在浏览器本次会话内显示；未接入真实AI或外部分析服务，体态观察采用示例内容。

报告上半部分为评分与数据，下半部分为专属方案及产品使用指南。指南全屏打开、缩放、保存原图；使用指引按钮打开原二维码。保存下载包含评分与方案长图及两张原始指南的ZIP。页面没有独立保存完成页。

响应式采用自然布局，不缩放手机画布。已在320–1920像素宽度、横屏以及电脑和手机尺寸下检查排版，并验证问答、计算、图片查看和导出。
